Design system reference

Kvitteria design system

A quiet, compact dark interface reskinned in Kvitteria's own green, set in Poppins over Montserrat. Extracted directly from the product mockup's live tokens and component classes.

Base structure — spacing, radius, shadow shape and the component set — comes from the underlying Nocturne system the mockup was built on. Two things were overridden for Kvitteria: the accent moved from Nocturne's blurple to this green, and the typefaces moved from Inter/Inter to Poppins (headings) / Montserrat (body). Everything on this page reflects those overrides, not Nocturne's own defaults.

Foundation

Farve

A dark ground with one accent voice — a green, at oklch hue 158–170 — carried across a 100–900 tonal ramp. This is a mono scheme: no second accent hue is used; --color-accent-2 resolves to the same value. Contrast comes from the tonal steps, not from added saturation.

Guidance

Brug

Gør
  • Tag alle farver, skrifttyper, afstande, radier og skygger fra variablerne — aldrig en hardcodet hex, fontnavn eller px-værdi.
  • Hold primærknapper som en outline; lad :focus-visible bære accentfarven.
  • Brug den kompakte afstandsskala (0,7×) — systemet er tæt med vilje.
  • Lad hierarki komme fra størrelse og luft, ikke fed vægt.
Gør ikke
  • Oversvøm ikke store flader med accentfarven — den optræder som streger og glød, ikke som flade.
  • Brug ikke ren sort eller hvid — alle værdier kommer fra ramperne.
  • Stak ikke tunge skygger — elevation her er en kant plus omgivende mørke.
  • Gør ikke overskrifter federe end 500 — det bryder skalaens rytme.
