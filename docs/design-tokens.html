Elevation & glow

On this dark ground, elevation is a hairline edge plus ambient darkness — never a stacked drop shadow. Each level pairs a border color with a shadow; sm has no shadow at all, so it's deliberately undefined rather than a shadow-less no-op.

elev-smHairline only (Neutral800). Resting cards, list rows.
ElevationMdNeutral700 edge + shadow(0,6,18,.55). Raised panels, the hero card.
ElevationLgNeutral500 edge + shadow(0,16,40,.65). Dialogs — the top layer.
HeroWash + HeroCornerGlow + HeroTextGlow
2.438,27 kr

Three layered tokens reserved for exactly one surface: the overview hero. A radial accent bloom off the top-left corner, a circular glow bleeding in from the top-right, and a colored text-shadow lighting the amount from behind.

Buttons

The implicit Button style is already the quiet secondary variant — a divider outline on nothing. The accent only shows up where it's opted into.

Primary is an accent outline, never a solid fill — hover and press are accent washes (14%/22%), not a color swap. Ghost drops the border entirely for an inline action. Icon buttons hold the 44×44 touch minimum even where the reference draws 36px.

Tags

KvTag pairs each background with its matching text colour.

TagAccent + TagText TagNeutral + TagTextNeutral TagOutline + TagTextOutline

Accent tags mark taxonomy (category, status of "done"); neutral tags carry counts and passive metadata; outline tags flag something pending or unresolved.

Forms & segmented control

Native controls, themed states — no custom widgets. A field reads as a well cut into the panel it sits on: Bg, not Surface.

Web
Mobil

The segmented control is a styled RadioButton, not two buttons — it keeps the exclusive-choice semantics and keyboard behavior for free. The checked option's ring is an inner Border stroke, which happens to land exactly where the reference's inset box-shadow does.

core:design-system — component

Callouts & notes

Two severities for a block of text the user must read before continuing.

Callout — accent edge over an accent wash. Form errors, "signed in as" panels — still a line and a glow, not a flood.
Note — a flat text wash, no border. A footnote that's information, not a problem.

Icons & brand

Every icon is a Phosphor glyph (FontIcons) taking the TextColor of whatever it sits in — one file, every density, no per-icon asset.

Kvitteria BrandMark + BrandMarkGlyph + Wordmark — the header mark on every screen, lit with AccentGlow.
